# Security policy

Only the latest release is supported.

Please report vulnerabilities through GitHub's private vulnerability reporting
feature on this repository's **Security** tab. Do not include credentials,
wallet secrets, private keys, or an exploitable proof of concept in a public
issue.

The miner never needs a wallet private key or seed phrase. Treat any request for
one as malicious. Solo mining needs only an RPC URL and a public payout address;
pool mining needs only the pool endpoint and a public payout address.
